# 🤖 GESCOM AI Analytics

> AI-powered Analytics Assistant for Field Operations & Meter Replacement using OpenAI, MySQL, Python, and Power BI.

---

## 📌 Project Overview

GESCOM AI Analytics is an end-to-end AI-powered analytics platform designed to help business users interact with operational data using natural language.

Instead of writing SQL queries or manually creating reports, users can simply ask questions such as:

> "Show today's completed meter installations."

or

> "Which contractor has the highest pending installations this week?"

The application converts the user's request into SQL, retrieves data from MySQL, generates AI-powered insights, and presents the results through an interactive interface and Power BI dashboards.
